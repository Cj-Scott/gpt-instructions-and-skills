# Presentation-Building Instructions

Use these prompts individually or in numbered order to develop a presentation from initial strategy through final editing.

| Step | Instruction | Purpose |
| --- | --- | --- |
| 1 | [Presentation Blueprint](01-presentation-blueprint.md) | Define the presentation's objective, audience, message, and overall plan. |
| 2 | [Slide Structure and Flow](02-slide-structure-and-flow.md) | Turn the blueprint into a coherent slide-by-slide sequence. |
| 3 | [Storytelling Presentation](03-storytelling-presentation.md) | Create a persuasive narrative arc that maintains audience attention. |
| 4 | [Visual Direction and Design](04-visual-direction-and-design.md) | Specify layouts, visual hierarchy, charts, diagrams, and styling. |
| 5 | [Complete Slide Content](05-complete-slide-content.md) | Write concise, presentation-ready content for every slide. |
| 6 | [Slide Clarity Editor](06-slide-clarity-editor.md) | Simplify and strengthen an existing presentation while preserving meaning. |

## Suggested workflow

Start with steps 1–4, then use step 5 to draft the deck. Run step 6 as the final editorial pass. When a presentation already exists, step 6 can be used independently.
